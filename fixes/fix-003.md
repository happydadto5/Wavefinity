# Fix 003 — Base Trim Drop-In Joint and Size Presets

Implementation thread title: **Base Trim Joint Imp #3**

## Goal

Replace the three current Base Trim section-joint choices with one universal, support-free, print-flat vertical drop-in dovetail joint. Replace separate free-form trim width/height controls with named square size presets, with Medium = 7.5 × 7.5 mm as the new default.

Also add a hidden physical-fit print: while a Base Trim design is active in the local app, Ctrl+Shift+click Print to Bambu Studio must generate and open a small two-piece Base Trim joint sample instead of the normal trim.

Keep the change narrow. Reuse the existing Base Trim splitter, seam frame, ring geometry, Bambu print path, and 3MF exporters. Do not create a second connector system.

Use these square presets:

- Small = 6.5 × 6.5 mm
- Medium = 7.5 × 7.5 mm — default
- Large = 10 × 10 mm
- XL = 15 × 15 mm
- XXL = 20 × 20 mm

Normal UI should expose one Trim size select instead of separate width and height fields.

Keep the saved representation compatible:

- New designs write the same preset value to both.
- Do not bump saved-design version 6 or Base Trim schema version 1.
- Existing legacy Base Trim files with non-preset or non-square dimensions must still load.
- When a legacy design is loaded, show a temporary selected option such as Legacy — 6 × 6 mm or Legacy — 6 × 8 mm. Do not mutate it until the user picks a preset.

## One joint only

Normal UI must no longer offer Snap tabs / Sliding dovetail / Puzzle joint.

Use:
- internal value: drop_in
- label: Drop-in dovetail

Old saved join_type values snap, dovetail, and puzzle must be accepted on load and normalized in memory to drop_in. New saves write drop_in.

Assembly is vertical: lift one section, align the key over the mating opening, and lower it. When both pieces lie flat, the wider head prevents horizontal pull-apart. Vertical removal is acceptable.

### Scaled geometry

The connector itself must scale with trim size. Add:

    def _joint_scale(spec: BaseTrimSpec) -> float:
        return min(spec.width_mm, spec.height_mm)

    def _joint_length(spec: BaseTrimSpec) -> float:
        return 0.55 * _joint_scale(spec)

Do not keep using a fixed BASE_TRIM_JOINT_LENGTH in fit planning. Any place reserving the male projection must use _joint_length(spec).

Replace _joint_profile() with one trapezoidal dovetail:

    def _joint_profile(spec: BaseTrimSpec) -> Polygon:
        length = _joint_length(spec)
        max_width = _joint_max_profile_width(spec)
        head = min(0.45 * _joint_scale(spec), max_width)
        neck = 0.70 * head
        if head <= 0 or neck <= 0:
            raise ValueError("Base Trim is too small for the drop-in joint.")
        return Polygon([
            (0.0, -neck / 2.0),
            (length, -head / 2.0),
            (length,  head / 2.0),
            (0.0,  neck / 2.0),
        ])

This is intentionally the current dovetail concept made scalable.

Keep the existing small male root overlap so the key robustly unions to its parent section.

### Full-height vertical insertion

The female opening must have no floor and no ceiling. It must be a full-height open slot so the other section can be lowered into it. No horizontal roof, bridge, snap arm, or hidden cavity.

Keep _joint_max_profile_width() as the material-safety limit.

For square outer dimensions:
- perimeter = 2 * (outer_x + outer_y)
- start = outer_x / 2.0, midpoint of front edge
- opposite = outer_x + outer_y + outer_x / 2.0, midpoint of back edge
- piece A = perimeter arc start -> opposite
- piece B = perimeter arc opposite -> start + perimeter
